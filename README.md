# 云听书 (CloudAudiobook)

全平台私人有声书库。播你自己 NAS / WebDAV / 本地存储里的有声书。

## 功能

- 音频播放（MP3、M4A、WAV、FLAC、OPUS等）
- 书源系统（WebDAV + SMB / 网络共享）
- 书架管理 + 播放历史
- 元数据编辑（书名、作者、演播者、封面）
- 播放进度自动保存
- 断点续播 + 自动播放下一集
- 定时暂停
- 数据同步（WebDAV 协议跨设备同步）
- Android 锁屏/通知栏媒体控制
- Material Design 3 暗色主题
